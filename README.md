# IPv6及IPv6+网络技术培训课程

获课：jzit.top/26811/

随着数字业务快速发展，万物互联、云网融合、算力调度等场景对网络能力提出更高要求，IPv6 作为下一代互联网基础协议，突破 IPv4 的固有局限，而 IPv6 + 在 IPv6 基础上叠加智能增强能力，共同构建面向数字化转型的新一代 IP 网络体系。本次培训从功能维度梳理 IPv6 与 IPv6 + 的核心价值，理解二者如何支撑各类新型业务落地。

IPv6 最基础、最核心的功能是提供海量地址资源。其采用 128 位地址空间，能够为每一台终端分配独立可路由地址，摆脱 IPv4 地址短缺、依赖地址转换的限制，满足物联网设备、智能终端、感知节点大规模接入需求，真正实现端到端直达通信。同时 IPv6 支持地址自动配置功能，终端可自主生成有效地址，简化网络部署，降低组网配置工作量。在报文转发层面，IPv6 简化报文头部结构，去除冗余字段，路由器转发逻辑更加简洁，路由聚合能力更强，有效压缩路由表规模，提升转发效率与吞吐能力。安全方面，IPv6 原生内置 IPSec 支持，可原生实现报文认证、加密，为端到端通信提供基础安全保障，相比 IPv4 外挂安全方案，安全能力嵌入协议底层，适配专线、政务、工业等对安全要求较高的场景。此外，IPv6 优化组播机制，新增任播地址类型，适配视频分发、集群访问等业务，为多媒体、广播类业务提供更好支撑。

IPv6 + 不是独立的全新协议，而是在 IPv6 基础上扩展的一组增强功能体系，把传统 IP 网络从 “尽力转发” 升级为可编程、可感知、可保障的智能网络。分段路由 SRv6 是 IPv6 + 的核心功能，它将路径信息封装在 IPv6 扩展头中，实现转发路径可编程，网络可按需规划转发路径，快速开通专线、云互联业务，替代传统复杂的标签协议，简化跨域组网。

网络切片功能是 IPv6 + 面向多业务承载的关键能力，在同一张物理网络上划分多个逻辑隔离网络，不同切片拥有独立带宽、时延和隔离策略，可分别承载 5G 业务、工业控制、高清视频、普通上网流量，保障高优先级业务不受其他流量干扰。随流检测功能可以实时采集业务流的时延、丢包、抖动数据，实现网络质量可视化，网络运维人员能够快速定位故障点，实现网络自愈和自动调优，改变传统网络被动排查的运维模式。

除此之外，IPv6 + 具备应用感知、新型组播、服务功能链调度等配套功能。网络能够识别上层业务特征，针对性提供差异化服务质量；新型组播提升大流量媒体分发效率；服务功能链可灵活编排防火墙、流量清洗等业务处理节点，按需调度业务处理流程。这些功能共同支撑算力网络、云边协同、远程医疗、工业互联网等低时延、高可靠业务，让网络不再只是数据通道，而是可以随业务需求动态调整的智能底座。

从功能演进逻辑来看，IPv6 解决 “能不能连” 的基础问题，提供充足地址、高效转发与原生安全底座；IPv6 + 解决 “连得好不好、管得灵不灵” 的进阶问题，赋予网络可编程、确定性保障、智能感知与自动化能力。二者相辅相成，是我国下一代互联网建设的核心技术路线。在实际落地中，通过双栈部署平滑过渡，逐步释放 IPv6 及 IPv6 + 的各项功能，持续赋能千行百业数字化转型。
